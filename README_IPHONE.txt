GYMTRACKER — установка на iPhone без Mac

1. Загрузите эти файлы на любой статический хостинг (например GitHub Pages).
2. Откройте адрес сайта в Safari на iPhone.
3. Нажмите «Поделиться» → «На экран Домой».
4. Запустите GymTracker с домашнего экрана.

Данные тренировок сохраняются локально на устройстве через localStorage.
Приложение работает офлайн после первого успешного открытия.

Важно: это PWA, а не подписанный IPA. Apple Developer Program не требуется.
